# 🧮 Calculator

> Uma aplicação de console interativa que realiza cálculos matemáticos básicos, desenvolvida como parte do curso de Fundamentos do C# da plataforma **balta.io**.

## 💻 Sobre o Projeto

Este projeto é uma calculadora simples desenvolvida em ambiente de terminal. O usuário pode escolher a operação matemática desejada através do símbolo correspondente e realizar múltiplos cálculos consecutivamente até decidir encerrar o programa. 

O objetivo principal foi praticar os fundamentos da linguagem C#, como estruturas de repetição, condicionais, funções e manipulação de entradas no console.

---

## 🚀 Funcionalidades

O sistema conta com um menu interativo que oferece as seguintes opções:
- ➕ **Soma** (Adição de dois valores)
- ➖ **Subtração** (Diferença entre dois valores)
- ✖️ **Multiplicação** (Produto de dois valores)
- ➗ **Divisão** (Quociente de dois valores)
- 🚪 **Sair** (Encerramento da aplicação)

## ⚙️ Como Executar o Projeto

### Pré-requisitos
Para rodar este projeto, você precisa ter instalado em sua máquina:
- [Visual Studio Code](https://visualstudio.com) (ou qualquer outra IDE de sua preferência)
- [.NET 9.0 SDK](https://microsoft.com)

### 🎲 Passo a Passo

1. **Clonar ou baixar o projeto:**
   Abra o terminal da sua máquina e clone o repositório:
   ```bash
   git clone https://github.com/LucasValimPereira/dev.git
   ```

2. **Abrir a pasta do projeto:**
   Navegue até a pasta onde o código foi baixado ou abra a pasta diretamente no VS Code.

3. **Executar a aplicação:**
   Abra o terminal integrado do VS Code (ou o terminal do seu sistema na pasta do projeto) e digite o comando abaixo:
   ```bash
   dotnet run
   ```
